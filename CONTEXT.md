# Personal Website

Derek's public web presence, linked from job applications for software engineering roles.

## Language

**Coming soon page**:
The minimal page served until the Personal website exists: name, a one-line description, and Contact links, with a note that a fuller site is on the way.
_Avoid_: Placeholder, landing page, splash page

**Personal website**:
The eventual full site that replaces the Coming soon page at the same URL.
_Avoid_: Portfolio (unless it actually showcases projects)

**Contact links**:
The outbound links a recruiter can act on from any page (e.g. LinkedIn, GitHub, email).
_Avoid_: Socials
